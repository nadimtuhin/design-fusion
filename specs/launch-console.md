# Launch console (proposed by Codex)

Bright and optimistic, close to Stripe: precise data with soft depth. The safest of the three. Preview: `themes/launch-console.html`.

- Tokens: --bg #F7F9FC, --surface #FFFFFF, --surface-alt #EEF2FF, --text #111827, --text-muted #526071, --border #D8E0EA, --primary #635BFF, --primary-dark #4338CA, --mint #0F9F78, --orange #F97316, --blue #1683E8, --danger #C2413B, --focus #1D4ED8, --shadow 0 12px 32px rgba(31,41,55,.10).
- Type: system sans at 700-850 with tight hero tracking, hero clamp(2.5rem,7vw,5rem), numbers in ui-monospace.
- Hero: centred, with a soft radial wash, CSS "signal dots", a tilted orbit outline and an orange status pill.
- Scan card: white, 20px radius, overlapping the hero, a segmented control, a 52px input, and a violet-to-blue gradient button with an arrow.
- Results: a "control room" layout with mint/violet/blue family top borders and tinted surfaces. Status always shows colour plus text.
- Motion: hover lifts 2px; rings animate once; rows highlight on open.
- Cut: external fonts, dark-first styling, repeated pill chrome.
